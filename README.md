# Sustainable Waste Management Portal

A location-aware web portal for reporting and tracking municipal waste-management issues. Citizens can submit geo-tagged reports, while administrators can monitor, filter, and route requests.

## Features

- Geo-tagged waste issue reporting
- Report status tracking
- Admin dashboard with status filters
- Automated request routing
- MySQL-backed report management

## Tech Stack

- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- REST APIs

## Setup

1. Clone this repository.
2. Import the database file into MySQL.
3. Update the database connection details.
4. Run the project through XAMPP or another PHP server.
5. Open the local URL in your browser.
